01 / OVERVIEW

Finding evidence in the dark.

Low-light appearance.
Complementary temporal evidence.

One video. Multiple questions.

VAULT brings anomaly description, classification, temporal grounding, and video question answering into one evaluation setting. The accompanying framework uses event activity to organize RGB observations and supplies aligned event images for joint reasoning.

Event modality. In the current experiments, events are simulated from source videos using v2e. They are a complementary representation of the RGB signal; this is not a claim of independently captured event-camera data or illumination invariance.

Implementation at a glance

TEA and SEL share 96 temporal bins and a 12 × 16 spatial grid. Current entry points request 16–24 RGB observations; allocation and deduplication can leave fewer. AEER supplies up to three anchors, each with three temporal-stage event images.

The framework uses Qwen3-VL’s existing visual pathway and language-model LoRA. The vision backbone and projection module remain frozen. No dedicated event encoder or auxiliary event loss is introduced.

The current inference anchor policy is v3; the historical full-model training cache records v2. The reported experimental snapshot should not be interpreted as an identical selection policy at training and inference.

WHY EVENTS?

Complementary cues.
A shared context.

Brightness changes can help organize motion-sensitive evidence under challenging illumination.

RGB challenges
  • Low contrast and underexposure
  • Motion blur and ambiguous appearance
  • Small or transient details are difficult to distinguish
Event representation
  • Encodes brightness-change polarity
  • Retains temporal activity information
  • Provides cues complementary to RGB appearance

Evaluation protocol & scope

Classification uses sample-averaged F1, not macro-F1. Temporal grounding uses the current evaluator’s mean video-level interval-union IoU, including its normal-video scoring rule. Description uses ROUGE-L from the documented comparison; a final GPT-score table is not available.

VQA accuracy aggregates option-permutation runs. Robust accuracy requires every cyclic option permutation for a question to be answered correctly. These are the same 915 questions, not additional independent questions.

All displayed completed configurations use checkpoint-420, but equal checkpoint indices alone do not establish matched training or visual-input budgets. These comparisons do not isolate a single causal contribution, establish statistical significance, or show illumination-stratified gains. Full-model macro-F1 does not improve; description gains are small and do not extend to every metric.
